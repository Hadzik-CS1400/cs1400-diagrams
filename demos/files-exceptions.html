Files & Exceptions Stepper

The file on disk is at the top and stays put. Next walks the arrow down the program beneath it, and you watch lines land, a file get emptied, and — in Part 5 — the arrow jump over code that never runs. The bar above the demo names the TODO each step is for, so you can watch it and then go and write it. Click any line to jump straight to it. Use ← → at any time — no need to click first.

▸ = the line running now  ·  ✗ never runs = a line an exception walked straight past  ·  Green = just written, or a file still open  ·  Purple = where the next read will start  ·  Red strike = erased, or never there  ·  Every line box ends in \n because the file really does.
