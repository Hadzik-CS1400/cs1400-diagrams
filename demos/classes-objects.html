Classes & Objects Stepper

The objects are at the top and stay put. Next walks the arrow down the program beneath it — including down into the methods — and you watch attribute boxes appear and change. Click any line to jump straight to it. Use ← → at any time — no need to click first.

▸ = the line running now  ·  Green ring + self = the object self is bound to right now  ·  Green = an attribute just set, or a value just replaced  ·  Blue ring = the attribute being read  ·  ✗ never runs = a line an early return walked straight past  ·  The purple box is the class: it holds the methods and none of the values.
