Dictionary Stepper

The dictionary is at the top and stays put. Next walks the arrow down the program beneath it, and you watch pairs appear, change and go. Click any line to jump straight to it. Use ← → at any time — no need to click first.

▸ = the line running now  ·  Blue ring = the pair being read  ·  Green = just added, or a value just replaced  ·  Purple = the pair this pass of the loop is on  ·  Red strike = gone, or never there  ·  A key is a name, not a position: there is no pair 0 unless 0 is a key.
