CS 1400 Steppers

Weber State University · Fundamentals of Programming (Python)

Each of these puts a short, real Python program on screen and walks a highlight down it one line per press, drawing what the program is actually doing beside the code. Before that, it shows what you are about to write — the session's tasks, with the decisions left blank.

Nothing to install, nothing to sign in to, and no internet needed once the page has loaded. Arrow keys work.

Module 9 · Code-Together 11 Dictionaries

Pairs drawn as a key box pointing at a value box, so a dictionary stops looking like a list with words for numbers. Watch 19 in student answer False while Ada is 19, the same line add a pair on one press and replace one on the next, a trailing space quietly make a second Ann, and seven presses of a loop do what one comprehension does.

 Module 10 · Code-Together 12 Files & Exceptions

A file drawn on disk, line by line, next to the program writing to it. Watch "w" empty a file at open before anything is written, a newline ride along into every line you read, a with block close a handle nobody closed — and an exception jump straight over two lines that go struck through and stay that way.

For students in the course: you already have these. An identical copy ships in your Code-Together starter repo at images/stepper.html — double-click it there and it works offline. This page exists so the link can be shared without asking anybody to clone a repository first.

Every program shown here is checked against real CPython before it is published: each demo is re-run under a line tracer and every state drawn on screen is compared with what the interpreter actually did.
